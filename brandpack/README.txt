ANGELS OASIS — BRAND PACK
Version 1.0, October 2026. Built from angelsoasisclhf.com. Prepared by KAM Team.

Angels-Oasis-Brand-Guidelines.pdf   The brand book (22 pages). Start here.

01-Logos/svg    Vector logos. Use these wherever you can.
01-Logos/png    Transparent PNGs. Lockups at 2400 and 800 px, marks at 1200 px, app icon at 1024/512/180/32 px.
                reversed = for Plum grounds (primary)      positive = for white, cream, linen
                mono-white / mono-plum / mono-black = one-color versions
                wordmark = no descriptor line, for small sizes   mark = wings and halo only
                _original-website-*.svg = the two files exactly as served by the website
02-Colors       Palette sheets (PNG) and all values as JSON and CSV. CMYK values are calculated; proof before printing.
03-Fonts        Fraunces and Inter web fonts (.woff2) with their SIL Open Font Licenses.
                For Word, Canva, PowerPoint and other desktop apps, install both from fonts.google.com.
04-Website-Photos   The six photos on the current site. The San Jacinto exterior has an MLS watermark: replace it.
05-Templates    Seven finished layouts (PNG) and templates.html, the editable source. Open it in a browser;
                it needs the 01, 03, 04 and 06 folders beside it.
06-For-Claude   BRAND.md (attach it to any Claude chat), plus design tokens as CSS and JSON.
_source-from-website   Raw files downloaded from the site.
